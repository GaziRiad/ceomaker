Signature element · the split name

The name is set in two expanded lines, first name left and surname right, with the portrait (or the headline and intro, if there is no portrait) between them. On load each line widens from 96% to 125% width. It is readable from the first frame and only its width changes. On scroll the two lines drift apart and the portrait slowly zooms. The states frame covers no image, one image, maximum hero copy and the longest name.

Motion · ease cubic-bezier(.16,1,.3,1) for timed motion; scroll-scrubbed effects run linear on a CSS scroll or view timeline

Every element's resting state is its final state. Under prefers-reduced-motion, in the editor (data-still="1") and without CSS timeline support, nothing moves and nothing is hidden. Scripted reveals only arm elements below the fold at load, so the page is complete without JavaScript. The name, headline and contact details are never hidden.

Choices made
  • The reference uses Vercetti (not on Google Fonts), Work Sans and Yatra One. Tempo uses Archivo's width axis instead: one family does both the display and body work, and the width axis lets the name stretch into place.
  • The reference's Webflow interaction data is compiled into its script and wasn't readable. The motion recreates the effects it shows (split name, drift, text rise, count-up, marquee, hover rows) using the values above.
  • It differs from Meridian on the same white ground through expanded grotesk at poster scale, square corners, an ink marquee band, a dark contact panel and scroll motion throughout.
  • Corners are square. Circles are used only for the badge, the CTA button, icon buttons and avatars.
  • The accent appears in small doses: eyebrow, kinds, focus numbers, ✦, the experience line and quote marks.
  • The badge is used for button labels up to 34 characters; longer labels get a square button. Phones always get a full-width button.
  • Experience lists over 10 items show 8 plus "Show N more".
  • Layout reads the container width (@container in React): under 640 phone, 640–999 tablet, 1000 and up desktop.
