DHandoff notes

Grid

Page max 1200, side padding clamp(20px, 4vw, 40px). One 12-track grid, gap 32 px rows, 24 px columns.

1280: 3 across, cards span 4 tracks, ≈357 px wide (picture 357 × 223).

390: 1 column, 20 px padding, cards 350 px (picture 350 × 219), gap 28 px.

Not drawn: 2 across from 640 px (span 6), 3 across from 1024 px.

Short last row: a remainder never sits alone. 2 left: the last row is 2 wide cards (span 6). 1 left: the last two rows become 2 + 2 wide cards. One card in total: a single wide card, centred (columns 4–9). At 2 across, an odd last card is centred at the same width. Pages of 12 always fill 3 across, so cards already shown never move when more load.

r = n % 3; wide = r==0 ? 0 : r==2 ? 2 : 4
col(i) = n==1 ? "4 / span 6" : i >= n - wide ? "span 6" : "span 4"

Card

<article class="blueprint lift">, neutral-100 fill, square, height stretches to the row.

Picture: desktop screenshot only, 16:10 (1280 × 800 source), object-fit cover, top-aligned, hairline below. The phone screenshot is not used on the card: at 350 px a phone in front would be about 80 px wide and hide part of the hero.

Body: padding 18 20 6, gap 8. Name h3, Barlow Condensed 600 24/1 caps, wraps with overflow-wrap:anywhere. Tag beside it (wraps under if needed). Description 15/1.45 neutral-800, line-clamp 3. Link pinned to the bottom, 44 px tall.

Click: one link, "View sample site" + ExternalLink 16, target _blank, rel noopener. Its ::after (absolute, inset 0) covers the card. Screen readers hear "View sample site · Meridian, opens in a new tab" (visually hidden suffix).

Hover: .lift (−3 px, shadow-md), link accent-600 + underline. Focus: article:has(a:focus-visible) gets the 2 px accent outline, offset 2. Reduced motion: no lift.

Show more

Server renders the first 12. "Show more templates", secondary lg + ChevronDown, centred 56 px under the grid (full width, 48 px tall on phones). Each press appends the next 12 in place with the normal reveal, moves focus to the first new card's link and announces "More templates added below." in a polite live region. The button is removed once everything is shown. No count anywhere, including the announcement.

Landing section

Between How it works and Against the alternatives, on the ground colour, 112 px padding. First 6 templates at 1280 (same balance rule if fewer exist, for example 5 today gives 3 + 2 wide), first 3 at 390. Then "See all templates" to /templates.

Motion

Only data-reveal (section heads, then cards at 0 / 110 / 220 ms by column) and the hover lift.
